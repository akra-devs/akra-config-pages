# Key Ddal — 개인정보처리방침

버전: 1.4.0

시행일: 2026-10-08

## 1. 운영자와 적용 범위

Akra Dev(대한민국 서울)는 Key Ddal: ASMR Keyboard를 제공합니다. 이 방침은 Google Play로 제공하는 Android 앱에 적용됩니다. 개인정보 및 지원 문의는 help@akra.kr로 보내주세요. 별도 계정 가입이나 서버에 저장되는 사용자 프로필은 제공하지 않습니다.

## 2. 기기에 보관하는 정보

앱은 보유 아이템, 선택한 키보드 구성, 재화, 탭·보상 진행 상황, 중복 보상 방지 기록과 일부 설정을 기기에 저장합니다. 광고 노출 빈도와 구매 권한 복구를 위한 기록도 로컬에 보관할 수 있습니다. 앱의 자체 코드가 이 진행 정보를 서버에 업로드하거나 계정과 동기화하지 않습니다. 앱 안의 타이핑 화면에 입력한 텍스트는 해당 세션의 메모리에만 존재하며 저장·전송하거나 분석 이벤트로 보내지 않습니다.

Android 시스템 키보드를 활성화하면 조합 중인 텍스트를 별도 입력기 프로세스의 메모리에서 처리하여 현재 입력 중인 앱에 전달합니다. 키딸은 이 텍스트를 저장·기록·업로드하거나 분석 이벤트로 전송하지 않습니다. 입력을 받는 앱은 자체 정책에 따라 텍스트를 처리합니다. 키보드 외형, 소리·진동 설정, 꾸미기 포인트와 보상 기록은 이 기기에 보관됩니다.

## 3. 광고와 개인정보 선택

앱에는 Google Mobile Ads와 Google User Messaging Platform(UMP)이 포함됩니다. 광고 요청이 허용되면 Google은 IP 주소, 앱·광고 상호작용, 진단 정보와 광고 ID 등 기기 식별자를 처리할 수 있습니다. 이 정보는 광고 제공·측정과 부정 사용 방지 등에 사용됩니다. 필요한 지역에서는 동의 메시지를 제공하며, 설정의 개인정보 선택 항목이 제공되는 경우 선택을 변경할 수 있습니다. 보상형 광고는 사용자가 선택하여 시청합니다.

앱의 AdMob 서비스는 Firebase 및 Google Analytics 서비스와 연결됩니다. 이에 따라 수집된 Analytics 데이터가 AdMob에 제공되고, AdMob 광고 수익 데이터가 Analytics에 제공되어 수익화·참여도와 재방문율 등을 분석하는 데 사용됩니다. 이 연결로 사용 통계를 꺼둔 사용자의 통계를 켜거나 광고 잠재고객을 활성화하지 않습니다. 광고 동의와 사용 통계 선택은 별도로 유지됩니다.

AdMob 미디에이션은 Unity Ads에도 광고를 요청하고 표시할 수 있습니다. Unity는 광고 제공·측정과 부정 사용 방지를 위해 기기 식별자, IP 주소와 대략적인 위치, 앱·광고 상호작용 및 SDK 진단 정보를 처리할 수 있습니다. 광고 요청에는 UMP와 적용되는 개인정보 선택을 반영합니다. 키보드 입력 텍스트를 Unity에 보내지 않습니다. 자세한 내용은 https://unity.com/legal/game-player-and-app-user-privacy-policy 를 참고하세요.

## 4. 사용 통계와 오류 진단

앱 1.0.6부터 사용 통계 공유는 처음 사용할 때 켜져 있습니다. 기존에 끄기로 선택한 설정은 유지하며, 앱 설정에서 언제든 끌 수 있습니다. 이전 버전에서는 사용자가 켠 경우에만 수집을 시작합니다. 활성화된 동안 Firebase Analytics는 앱 실행·세션·화면 등 이용 이벤트, 앱 인스턴스 식별자, 앱·기기 정보와 대략적인 지역 정보를 처리할 수 있습니다. 앱의 Analytics 광고 ID 수집 및 기본 광고 개인화 신호는 비활성화되어 있으며 사용자 ID를 지정하지 않습니다. Firebase Crashlytics는 충돌·앱 멈춤 진단을 위해 스택, 기기·앱 정보와 설치 식별자를 처리할 수 있습니다. 앱 자체 진단에는 제한된 오류 코드와 정제된 문맥만 전달하며 Type 텍스트, 인증 정보 또는 원본 구매 토큰을 넣지 않습니다.

## 5. 설정 다운로드와 외부 제공자

앱은 akra.kr의 GitHub Pages에서 서명된 공지, 업데이트 기준, 번역 및 정책을 HTTPS로 내려받습니다. 이 연결로 IP 주소와 요청 경로 등 일반 요청 정보가 호스팅 제공자에게 전달됩니다. 설정 요청에 게임 진행이나 입력 텍스트를 첨부하지 않습니다. Google 서비스와 GitHub는 각자의 개인정보 고지에 따라 정보를 처리하며 다른 국가에서 처리될 수 있습니다. 자세한 내용은 https://policies.google.com/privacy , https://firebase.google.com/support/privacy , https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 를 참고하세요.

## 6. 구매와 결제

현재 원격 설정에서는 앱 내 신규 구매를 비활성화합니다. 구매·복원 기능이 제공되는 경우 결제는 Google Play가 처리하며 앱은 결제 카드 정보를 받지 않습니다. 앱은 거래 상태와 권한 확인에 필요한 정보를 처리할 수 있고, 로컬 기록에는 원본 구매 토큰 대신 해시를 사용합니다. 새로운 구매 검증 서비스를 추가하면 관련 데이터 처리 내용을 먼저 갱신합니다.

## 7. 보관과 삭제·권리 요청

로컬 진행 정보와 설정은 앱 데이터 삭제 또는 앱 제거 시 삭제됩니다. Type 텍스트는 세션이 끝나면 유지되지 않습니다. 원격 설정은 오프라인 사용을 위해 기기에 캐시됩니다. Google·Unity·GitHub의 서비스 기록은 각 제공자의 목적·설정·정책에 따라 보관되며 앱 삭제만으로 해당 기록이 모두 삭제되는 것은 아닙니다. 문의 이메일로 전달한 내용은 요청 처리와 필요한 후속 대응에 사용합니다. 열람·정정·삭제 등 개인정보 관련 요청은 help@akra.kr로 보내주세요. 요청을 확인하는 데 필요한 최소한의 정보를 요청할 수 있으며, 관련 법률이 적용되는 범위에서 처리합니다. 앱에 계정이 없으므로 별도 계정 삭제 절차는 없습니다.

## 8. 권한과 보안

선택형 로컬 알림을 위해 알림 권한을 요청하며, 진동은 촉각 피드백에 사용합니다. 마이크로 소리를 녹음하지 않습니다.

네트워크 접근은 광고·동의·진단·통계·설정 다운로드에 사용됩니다. 앱은 연락처, 카메라, 마이크, 정밀 위치 또는 사진 접근을 요청하지 않습니다. 소리는 앱에 포함된 파일로 재생됩니다. 원격 설정은 HTTPS와 서명·무결성 검증을 사용하며, 검증 실패 시 유효한 캐시나 기본 설정을 사용합니다. 이러한 조치가 절대적인 보안을 보장하지는 않습니다.

## 9. 이용 대상과 변경 안내

앱은 만 13세 이상을 대상으로 하며 어린이를 대상으로 설계하지 않았습니다. 거주 지역에서 보호자 동의 등 추가 요건이 적용되면 해당 요건을 따라야 합니다. 개인정보 처리에 중요한 변경이 있으면 앱 공지 또는 이 페이지에 안내하며 필요한 동의를 별도로 받습니다. 문서의 버전과 시행일을 표시하고 게시된 이전 버전을 보관합니다.
